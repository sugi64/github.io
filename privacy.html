Privacy Policy

Otong Uploader · Last updated: 28 September 2026

This Privacy Policy explains what data the application Otong Uploader (“the app”) accesses, why it accesses it, how it is stored, and how it can be deleted. Otong Uploader is a private, personal-use tool operated by a single individual for his own YouTube channel. It is not a public service and it has no other users.

1. Google user data we access

When the app’s owner signs in with his Google Account, the app requests the following authorization:

  • https://www.googleapis.com/auth/youtube.force-ssl — permission to manage the owner’s own YouTube account data (upload videos, edit video metadata, set thumbnails and visibility).

As a result of that authorization, Google provides the app with the owner’s channel identifier, the OAuth access token, and the OAuth refresh token. The app does not request, collect or store any other Google user data, and it does not access data belonging to any other Google Account.

2. How the data is used

  • Uploading video files that the owner has produced to the owner’s own YouTube channel.
  • Setting and updating the title, description, tags, category, privacy status and thumbnail of those videos.

The data is used for no other purpose. It is never used for advertising, profiling, analytics, training machine-learning models, or any commercial purpose.

3. Storage and security

OAuth credentials (client secret, access token and refresh token) are stored only as local files on the owner’s own computer and on his own private, password-protected home server, which is not reachable from the public internet. Video files are stored on the same private devices. There is no public server, no cloud database and no third-party hosting of user data.

4. Sharing and disclosure

We do not sell, rent, trade or share Google user data with any third party. Data is transmitted only to Google’s own APIs (accounts.google.com, oauth2.googleapis.com, www.googleapis.com/youtube) for the purpose of publishing videos to the owner’s channel. No person other than the owner can read the stored credentials.

5. Google API Services Limited Use disclosure

Otong Uploader’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. Retention and deletion

Credentials are kept only for as long as the owner wants to keep using the app.

  • Access can be revoked at any time from the Google Account permissions page: myaccount.google.com/permissions. Revoking access immediately invalidates the app’s tokens.
  • Deleting the local token.json / client_secret.json files removes the stored credentials from the owner’s devices.
  • Videos remain under the owner’s control in his own YouTube channel and can be deleted there at any time.
  • To request deletion of any data related to this app, write to the contact address below.

7. Children

The app is not directed to children and is not available to the public.
